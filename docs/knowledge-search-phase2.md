# 知识检索第二阶段：质量与结果浏览

在已有权限过滤的语义候选集内重新排序，不新增中间件、不调用生成模型、不需要重建已有索引。

- 按索引 metadata 验证并去除用于 embedding 的标题前缀后，识别纯标点/表格分隔符片段。
- 保留原始语义阈值，正文词项覆盖最多加权 0.15，章节覆盖最多加权 0.05。英文按词、中文按双字词项匹配；这是轻量词项重排，不是独立全文召回或模型 reranker。
- 同文档相同正文去重，稳定排序后最多返回 10 条；无匹配不补充无效结果。智能问答的原有 MMR 排序不变。
- 页面展示结果来自多少份文档，可在已返回结果中按文档筛选；长片段默认折叠，支持展开。下载与知识库入口保留。

## 已验证

- search_quality 3 项测试：标题前缀后的无效片段、直接匹配排序、阈值/去重/数量边界。
- 前端检索组件测试与生产构建。
- admin 真实接口：MLFQ 时间片耗尽降级规则首条命中标准 MLFQ；知识铸造炉问题首条命中第三站，结果无纯分隔符。

## 边界

仍为单知识库语义召回；词项重排只作用于已召回候选。尚未引入 BM25、跨库搜索、独立 reranker 或大规模 ACL 检索。单库 1000 份文档上限仍按第一阶段明确报错。排序改善经过上述样例验证，不能视为完整质量基准。

部署应同步更新 rag-service 与 web。源码可正常镜像构建；现有本地部署复用镜像运行环境，更新应用文件，不改变索引卷。

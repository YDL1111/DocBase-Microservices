# DocBase 项目文档

这里集中记录 DocBase 的系统设计、接口契约和本地运行方式。文档面向项目使用者、维护者与代码审查者，内容以当前仓库实现为准，不记录开发批次、临时验收结果或历史任务编号。

## 阅读路线

第一次了解项目，建议按以下顺序阅读：

1. [系统架构](architecture/overview.md)：了解服务边界、数据归属和核心链路。
2. [身份认证与数据权限](architecture/security.md)：了解 JWT、RBAC、菜单归属和知识可见范围。
3. [RAG 文档处理与问答链路](architecture/rag.md)：了解解析、分块、检索、重排、生成和引用。
4. [本地运行手册](runbook/README.md)：配置环境并启动完整系统。
5. [API 接口索引](api/README.md)：按服务查询 HTTP 契约。
6. [事件契约](events/README.md)：理解文档入库和状态回传的异步协作。

## 维护约定

- 接口、事件或环境变量发生变化时，应同步更新对应文档。
- 文档描述稳定的业务能力和设计约束，不堆放开发过程日志。
- 示例不得包含真实密码、Token、API Key、对象存储地址或用户数据。
- 路径统一以 Gateway 对外地址为准；内部接口会明确标注“仅服务间调用”。
- 代码与文档冲突时，以当前实现为准，并在同一次改动中修正文档。
